# Host Talent AI — V1.5

Copilote opérationnel pour cabinets de recrutement et cabinets de conseil RH.

## Fonctions disponibles

- création de missions ;
- import CV PDF/DOCX/texte ;
- extraction de compétences ;
- détection des mentions négatives ou limitées ;
- matching explicable candidat ↔ mission ;
- questions de préqualification ;
- recherche dans le vivier ;
- classement des candidats ;
- pipeline par mission : à examiner, short-list, contacté, entretien, présenté client, offre, recruté, en attente, non retenu ;
- notes recruteur et prochaine action ;
- export CSV du vivier ;
- recalcul global des matchings ;
- dashboard opérationnel.

## Principe de sécurité métier

Le score sert d'aide à la revue. Une absence de preuve dans le CV n'est pas assimilée à une incompatibilité et aucune décision de recrutement ou de rejet n'est automatisée.

## Limite avant utilisation avec des données réelles de tiers

La V1.5 reste un pilote fonctionnel. Avant ouverture à un cabinet externe avec de vraies données candidats, ajouter authentification, multi-tenant, contrôle des droits, politique de conservation et stockage sécurisé des fichiers CV originaux.
